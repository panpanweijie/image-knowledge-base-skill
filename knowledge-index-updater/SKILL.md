# Knowledge Index Updater

Use this skill after new materials are added, collages are generated, image folders are summarized, or folder structure changes.

## Workflow

1. Read root rules first, especially the preferred index names and query path.
2. Update the nearest local folder index first, such as `资料索引.md`.
3. Use a concise fixed structure for image folders: scope, count/range, material type, collage link, rough sections, key conclusions or reusable facts, suggested originals to open, retrieval keywords.
4. Update parent/root indexes only when structure, counts, reading routes, keywords, or major concepts changed.
5. Preserve existing user notes and only edit the relevant section.
6. Verify Markdown links in touched root/parent indexes before finishing.

## Indexing Rules

- Prefer relative links inside folder indexes.
- Use Chinese, English, abbreviations, and common aliases in keywords when useful.
- For light indexing, avoid per-image notes and full OCR.
- For detailed reads, write progress after each 10-20 images so work survives context compaction.
- If an index and source material disagree, treat source material as canonical and update the index.
